# CiteCheck

Demo del TFG de Jorge Barrado: detección y revisión de citas académicas
incorrectas, con lector de PDF y extracción de referencias.

Código: https://github.com/jorgebarrado/TFG

Es una demo: los datos (cuentas, reportes, PDFs subidos) se borran cada vez que
el Space se reinicia.
